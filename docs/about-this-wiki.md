# About this wiki

**Forever Codex** catalogues *World of Warcraft: Forever* from public sources. It is an unofficial fan project and is not affiliated with or endorsed by Blizzard Entertainment.

## How it was built

- Research covered official Blizzard posts, the Warcraft Wiki, Wikipedia, and major news and guide sites, up to **7 November 2026** (three days after launch).
- Everything is **paraphrased**. No source text is reproduced at length.
- Every source is listed on the [Sources](sources.md) page.

## Conventions

| Marker | Meaning |
|---|---|
| **Conflict** (note box) | Sources disagree. Every version is listed |
| *unconfirmed* | Comes from a single, non-official source |
| *fan source* | From a fan or guide site of lower reliability |
| **new** | New in Forever (vs. original Classic) |

When the beta Class Deep Dives and the later pre-launch notes disagree, the wiki follows the **newer** pre-launch notes.

## Known gaps

- Boss rosters and loot for The Drowned City, Krol'dok Stronghold, Alcaz Prison, Blackmaw Hold and Shaper's Terrace
- Raid loot tables and tier sets
- Mount Hyjal and Shen'dralas quest content
- An official battleground list and brackets for WSG, AB and AV
- A Hardcore launch date and its full rules
- Official player counts

## Contributing

Each page has an edit link (the pencil icon) that opens the Markdown source on GitHub. The site is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

```bash
pip install -r requirements.txt
mkdocs serve
```
