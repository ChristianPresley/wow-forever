# FAQ

??? question "Do I need to buy WoW: Forever?"
    No. Any WoW subscription or Game Time includes it. Only the **Skyborne** race costs extra (Heroic Pack, $29.99 or more). See [Editions](editions.md).

??? question "Is it on Steam or consoles?"
    No. Windows and macOS through Battle.net only. Gamepad support is in beta.

??? question "What is the level cap? Will it increase?"
    60, **permanently**. There will be no traditional expansions. Blizzard adds new content at level 60 or lower.

??? question "Is there flying? Level scaling?"
    Neither.

??? question "WoW Token? Boosts?"
    Neither. Blizzard has no plans for them at this time.

??? question "Which realm do I select?"
    There are no realms. You pick a **Ruleset** (Normal, PvP, RP, RP-PvP, later Hardcore). Each one is a regional megaserver. See [Rulesets](rulesets.md).

??? question "Can I play with the other faction?"
    No. Groups, guilds, trade and mail work only in the same faction and ruleset. Battlegrounds can mix rulesets, but not Hardcore.

??? question "Can I move a character between rulesets?"
    Generally no. Dead Hardcore characters can transfer out.

??? question "When do raids open?"
    **9 December 2026**: Barrow Deeps (10), Hyjal Summit (20), Onyxia's Lair (40). See [Raids](../content/raids/index.md).

??? question "When is Hardcore?"
    Winter 2026/27. Blizzard has not announced the date. See [Hardcore](hardcore.md).

??? question "Is the story canon with retail?"
    No. It is a separate "time bubble" continuity in year 1 (25 ADP). See [Lore](../world/lore.md).

??? question "Do add-ons work?"
    Yes, with the API restrictions of the Midnight era. The design goal is that you do not need any add-ons. See [Add-ons & UI](../systems/addons.md).

??? question "What's new for classes?"
    New race/class combinations, reworked talent trees, dual spec at 40 and new abilities. See [Classes](../characters/classes/index.md).

??? question "Can I keep my retail or Classic progress?"
    No. Forever characters start from the beginning. Some purchased cosmetics work in both retail and Forever.

??? question "Is it a good game for new players?"
    Blizzard thinks so. All players level at about the same speed, and the story starts at the beginning of WoW.
