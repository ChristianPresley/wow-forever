# FAQ

??? question "Do I need to buy WoW: Forever?"
    No. It is included with any WoW subscription or Game Time. Only the **Skyborne** race costs extra (Heroic Pack, $29.99 or more). See [Editions](editions.md).

??? question "Is it on Steam or consoles?"
    No. Windows and macOS through Battle.net only. Gamepad support is in beta.

??? question "What's the level cap? Will it go up?"
    60, **permanently**. There will be no traditional expansions; new content is added at or below 60.

??? question "Is there flying? Level scaling?"
    Neither.

??? question "WoW Token? Boosts?"
    Neither, and none are currently planned.

??? question "Which realm should I pick?"
    There are no realms. You pick a **Ruleset** (Normal, PvP, RP, RP-PvP, later Hardcore). Each one is a regional megaserver. See [Rulesets](rulesets.md).

??? question "Can I play with the other faction?"
    No. Grouping, guilds, trade and mail are limited to the same faction and ruleset. Battlegrounds can mix rulesets, except Hardcore.

??? question "Can I move a character between rulesets?"
    Generally no. Dead Hardcore characters can transfer out.

??? question "When do raids open?"
    **9 December 2026**: Barrow Deeps (10), Hyjal Summit (20), Onyxia's Lair (40). See [Raids](../content/raids/index.md).

??? question "When is Hardcore?"
    Winter 2026/27. The date has not been announced. See [Hardcore](hardcore.md).

??? question "Is the story canon with retail?"
    No. It is a separate "time bubble" continuity set in year one (25 ADP). See [Lore](../world/lore.md).

??? question "Do add-ons work?"
    Yes, under Midnight-era API restrictions. The design goal is that you don't need any. See [Add-ons & UI](../systems/addons.md).

??? question "What's new for classes?"
    New race/class combinations, reworked talent trees, dual spec at 40 and new abilities. See [Classes](../characters/classes/index.md).

??? question "Does my retail or Classic progress carry over?"
    No. Forever characters start fresh. Some purchased cosmetics work in both retail and Forever.

??? question "Is it a good game for new players?"
    Blizzard thinks so: everyone levels at roughly the same pace, and the story starts at WoW's beginning.
