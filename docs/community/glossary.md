# Glossary

Classic+
:   The community's name for a continued, expanded Classic. Forever is Blizzard's version.

Camelot
:   The internal codename for Forever. It also appears in the client API (`WOW_PROJECT_CAMELOT`). Modern WoW is "Standard".

Time bubble
:   The separate continuity of Forever: permanently year 1 (25 ADP), and never canon with retail.

Found photographs
:   Chris Metzen's term for new stories that feel as if they were always part of Classic.

Ruleset
:   Replaces realms: Normal, PvP, Roleplay, Roleplay PvP, and Hardcore (later).

Mega-realm / Megaserver
:   The single regional world for each ruleset. It uses layering.

Layering
:   Multiple copies of the world in 1 mega-realm. The game uses them to manage load.

Experience Preset
:   The *Classic* or *Enhanced* settings bundle that you select at first login.

SD / HD models
:   A per-character choice between the original and the high-definition character models.

Legacy System
:   The replacement for achievements. You get account-wide **Legacy Points** from **Legacy Challenges**. You spend them in per-character **Legacy Trees** (Professions, Adventure, Resourcefulness). Point totals unlock **Legacy Rewards**.

Spelunker
:   The Legacy dungeon challenges (Novice, Experienced, Master).

Camping / Camp Features
:   Shared rest sites that you build from a campfire. They have up to 3 profession-crafted features that give buffs after 60 seconds.

Skyborne / shen'dorei
:   The new race, descended from the Shen'dralar exiles. **High Order** (Alliance, Mage) and **Windshapers** (Horde, Shaman).

Galestrider
:   The Skyborne racial mount.

Prideclaw
:   A new creature family. The *Cerulean Prideclaw* is the Heroic Pack mount.

Al'Aketh
:   The Al'Akir cult on Zephras Isle.

Merchant's Favor
:   A character-bound profession currency for high-end recipes.

Azeroth Commerce Authority / Durotar Supply and Logistics
:   The faction-mirrored trade reputations, which come from Season of Discovery.

Temporary Economy Hold
:   An anti-RMT freeze on trade, mail, the guild bank and the AH during an investigation.

Obfuscated items
:   Encrypted item stats that unlock region-wide when a player discovers the item.

Field of Honor
:   The PvP season journey with weekly milestones. Weeks 4, 7 and 10 give Legacy Points.

Rank Points
:   The weekly-capped currency that moves you through PvP Ranks 1–14 each season.

Emboldened Seal
:   Upgrades blue PvP gear to epic. Needs a minimum rank.

Banes
:   The Warlock curse category (Agony, Doom, Havoc). Only 1 per Warlock per target.

Darkspear Islands
:   The new 15v15 battleground: Darkspear Raiders vs Theramore Expeditionary Force.

Barrow Deeps / Hyjal Summit
:   The new 10- and 20-player raids that open 9 Dec 2026.

Taldramir, the Whispering Wood
:   Forever's first legendary, a staff.

Launch Celebration
:   The launch event that runs until early December.

Gol-pat
:   The Korean term for GDKP, which is still allowed in Korea.

Lexicon Client
:   A third-party data collector for WarcraftDB.
