# Alcaz Prison

*Also written "Alcaz Island Prison".*

| | |
|---|---|
| **Type** | 5-player dungeon (new in Forever) |
| **Level** | 48–53 (LFG 48–55) |
| **Location** | Alcaz Island, Dustwallow Marsh. The entrance is in the basement of a large building (~75, 15) |
| **Faction** | Both |
| **Bosses** | 1 known (one source counts 5) |

## Overview

A long-sealed prison on Alcaz Island has opened, and the **Defias Brotherhood** and **naga** are fighting over it. Blizzard says rumors point to high-value prisoners inside, possibly including **King Varian Wrynn**. In the original first year of WoW, the king was missing.

## Known details

- **Boss:** **Blazeroar** (revealed through a Legacy challenge). The rest of the roster is unconfirmed.
