# Roadmap

Blizzard ships Forever updates **by season**, not in numbered Classic-style phases.

  **Done**{ .pill .pill--fixed }

  **Coming soon**{ .pill .pill--soon } **Official**{ .pill .pill--official }
- **Winter 2026/27** **Hardcore** ruleset  
  **Planned**{ .pill .pill--planned } **Stated**{ .pill .pill--outline } by developers. BlizzardWatch notes it is not on the official roadmap graphic
- **Spring 2027** 2 new raids (10- and 20-player), 2 new dungeons, new quests and a new playable area, a new **legendary questline**, PvP season refresh  
  **Planned**{ .pill .pill--planned } **Official**{ .pill .pill--official } (roadmap)
- **Summer 2027** A **revamped "iconic" raid** (unnamed; Molten Core is the community's guess), a new raid, expanded world content, 2 new dungeons, PvP season refresh, **profession and Legacy updates**  
  **Planned**{ .pill .pill--planned } **Official**{ .pill .pill--official } (roadmap)
- **Beyond** "Frequent major updates" for years
