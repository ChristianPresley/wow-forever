# Roadmap

Blizzard ships Forever updates **by season**, not in numbered Classic-style phases.

| When | What | Confidence |
|---|---|---|
| 17 Sep – 23 Oct 2026 | Beta (levels 1–30; 4 of the 9 new dungeons playable) | **Done**{ .badge .done } |
| **4 Nov 2026** | **Launch:** 9 new dungeons, Darkspear Islands, PvP Season 1 | **Done**{ .badge .done } |
| **9 Dec 2026** | **Raids:** Barrow Deeps (10), Hyjal Summit (20), Onyxia's Lair (40) | **Official**{ .badge .official } |
| Winter 2026/27 | **Hardcore** ruleset | **Stated**{ .badge .stated } by developers. BlizzardWatch notes it is not on the official roadmap graphic |
| **Spring 2027** | 2 new raids (10- and 20-player), 2 new dungeons, new quests and a new playable area, a new **legendary questline**, PvP season refresh | **Official**{ .badge .official } (roadmap) |
| **Summer 2027** | A **revamped "iconic" raid** (unnamed; Molten Core is the community's guess), a new raid, expanded world content, 2 new dungeons, PvP season refresh, **profession and Legacy updates** | **Official**{ .badge .official } (roadmap) |
| Beyond | "Frequent major updates" for years | **Official**{ .badge .official } intent |
