# Class & Race Guides

Full walkthroughs for every class, plus a **race add-on** for each of the 56 legal race/class combinations.

- **Class guide** — the core walkthrough: talents and specs, rotations, a 1–60 leveling route, dungeons, raid preparation for 9 December, PvP, gear and professions.
- **Race add-on** — read alongside the class guide. Covers what changes for that race: racials in practice, starting zone and early route, faction-specific quests and trainers, and best uses of the race.

!!! info "Current as of 7 November 2026"
    Forever launched three days ago. Guides follow the latest pre-launch notes and launch-week hotfixes; expect numbers to shift. See [Classes](../characters/classes/index.md) and [Races](../characters/races.md) for the reference data.
