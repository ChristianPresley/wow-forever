## How to read this page

The Mage has 53 talents in 3 trees. You get 1 talent point for each level from 10 to 60, for a total of 51 points.

- **Opens at:** the number of points that you must spend in the same tree before the row opens. Each row needs 5 more points.
- **Max:** the maximum rank of the talent.
- **Leveling:** the value of the talent when you quest and do dungeons from level 10 to 59.
- **PvE:** the value at level 60 in dungeons and raids. This is damage, healing or tank value, for the role of the tree.
- **PvP:** the value in battlegrounds and world PvP.

**S**{ .tier .tier-s } Core. Take it in each build of that type. **A**{ .tier .tier-a } Strong. Take it when you can. **B**{ .tier .tier-b } Good. Use it to fill points. **C**{ .tier .tier-c } Situational or a personal preference. **D**{ .tier .tier-d } Do not take it.

## FAQ

??? question "Where is Missile Barrage in the tree?"
    In the launch client, Missile Barrage is in Arcane row 2. It needs 5 Arcane points and has 2 ranks. Blizzard's deep dive from the beta gave a different position.

??? question "Is Winter's Chill a raid talent?"
    No. In Forever, Winter's Chill only increases the damage of your next Cone of Cold. It does not increase crit chance for the raid.

??? question "Do I need hit talents?"
    Precision in Frost row 1 gives 6% hit for all spells. The launch client has no Arcane Focus talent. Thus, each raid build takes Precision 3/3.

??? question "When do I respec?"
    Dual spec costs 50g at level 40. Keep the leveling build in one spec. Use the second spec for dungeons or PvP.
